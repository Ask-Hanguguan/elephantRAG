简介：
本期末复习系统基于 LangChain 与 ChromaDB 构建轻量化 RAG 知识库，针对500 万字以内的课程文本数据搭建智能检索问答能力，可实现教材、课件、复习资料的智能解析、向量存储、语义检索与智能答疑，适配期末备考复习场景。

可加载文件："txt", "pdf", "csv","html","md","docx","xlsx","pptx"
CCH:文档标题、文档摘要、章节/子标题
Fusion Retruval：稀疏检索（BM25）+稠密检索  【各召回10条】---> 采用RRF 融合重排选取top5
Relevant Segment Extraction:将上一步的top5相关块重构为连续段落
Memo RAG：记忆对用户有用的高分文档

会话长期归档记忆：
-处理指代类追问
-保留用户临时约束
-快速复用近期结论，无需重复检索文档，降低时延与 Token 消耗
缺点：只有问答摘要，丢失文档完整细节；多轮后窗口溢出，早期文档信息丢失。

. Document Memo 文档记忆
-保存完整原文信息，当追问需要深挖文档冷门章节、多章节关联推导时提供完整素材
-跨会话复用
-修复问答记忆的信息缺失
